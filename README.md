# 🧪 Bài 7: Hoá Trị và Công Thức Hoá Học (KHTN 7)

> **Học Liệu Số Tương Tác Môn Khoa Học Tự Nhiên 7**  
> **Bộ sách:** Kết nối tri thức với cuộc sống (Chương trình GDPT 2018)  
> **Tác giả:** Thầy Lê Văn Thắng • Trường TH & THCS Phước Hưng

## 🌟 Giới Thiệu

Website bài học tương tác hoàn chỉnh số hoá nội dung Bài 7 - Hoá trị và công thức hoá học:
- **Chuẩn 100% danh pháp quốc tế IUPAC:** *hydrogen, oxygen, nitrogen, sulfur, sodium, potassium, calcium, magnesium, copper, water, methane, calcium carbonate, copper(II) sulfate...*
- **Giao diện hiện đại & Gamified:** Đăng nhập theo Họ tên & Lớp học sinh, thanh tiến trình thời gian thực, tích luỹ Sao thưởng ⭐, âm thanh tương tác Web Audio API.
- **Mô hình phân tử vector SVG:** Phân tử nước $H_2O$ với góc liên kết $104{,}5^\circ$ chuẩn hình học không gian và hoá học.
- **Bộ công cụ trực quan:** Máy tính % khối lượng tự động, Bảng tra cứu hoá trị thông minh 7.2 & 7.3 kèm bộ lọc.
- **Hệ thống kiểm tra 20 câu (Thang điểm 10,0):**
  - Trắc nghiệm 16 câu gồm 4 hình thức đổi mới: 4 lựa chọn, Đúng/Sai, Ghép đôi, Điền khuyết.
  - Tự luận 4 câu có biểu điểm chấm chi tiết và đáp án chuẩn SGK.
  - Tự động xuất **Phiếu Báo Điểm Chính Thức** kèm xếp loại, lời nhận xét của giáo viên và hỗ trợ In/Lưu PDF.

## 🚀 Hướng Dẫn Sử Dụng

1. Clone hoặc tải mã nguồn về máy:
   ```bash
   git clone https://github.com/winphuochung/bai-7-hoa-tri-cong-thuc-hoa-h-c.git
   ```
2. Mở file `index.html` trực tiếp bằng trình duyệt (Chrome, Edge, Cốc Cốc, Safari...).
3. Để chạy trên mạng nội bộ hoặc chiếu trong lớp học:
   ```bash
   python -m http.server 8080
   ```
   Sau đó truy cập `http://localhost:8080`.
